# AI 提示词生成器

一个 AstrBot 插件，用于根据用户的人设描述自动生成专业、结构化的 AI 系统提示词。

## ✨ 功能特点

- 🎯 根据简单的人设描述生成完整的 AI 系统提示词
- 📝 包含角色定义、核心任务、行为准则等完整结构
- 🛡️ 支持无限制提示词生成（虚拟情景）
- 💬 使用转发消息格式发送生成的提示词
- ⚙️ 支持自定义 LLM 服务商
- 🎨 支持自定义生成提示语

## 🚀 快速开始

### 1. 安装插件

将插件文件放入 AstrBot 的 `plugins` 目录：

```bash
# 复制插件文件到 AstrBot 插件目录
cp -r astrbot_plugin_Xx_AIprompt /path/to/astrbot/plugins/
```

### 2. 配置插件（可选）

在 AstrBot 的 WebUI 中配置：

- `system_prompt_template`: 生成提示词时使用的系统指令模板
- `generating_prompt`: 生成提示词前发送的提示语（支持 `{role}` 占位符）
- `provider_id`: 指定用于生成提示词的 LLM 服务商 ID（留空则使用当前对话的 LLM）

### 3. 使用指令

在 QQ 中发送以下指令：

```
/prompt 一个专业的 Python 编程助手，擅长代码审查和调试
```

## 📖 指令说明

### 1️⃣ `/prompt [人设描述]`

生成 AI 提示词

**示例**：
```
/prompt 一个专业的 Python 编程助手
/prompt 一位温柔的心理咨询师
/prompt 日语学习老师，擅长口语练习
/prompt 原神中的雷电影
```

### 2️⃣ `/prompt_help`

显示帮助信息

### 3️⃣ `/prompt_config`

查看当前配置

## 💡 使用技巧

1. **人设描述越详细，生成的提示词越精准**
   - ✅ 好：`一位经验丰富的雅思写作老师，擅长逻辑论证和词汇运用`
   - ❌ 差：`老师`

2. **可以指定职业、性格、专业领域**
   - `一个幽默的健身教练，用轻松的方式指导训练`
   - `专业的法律文书助手，严谨细致，熟悉各类法律条文`

3. **支持多种触发方式**
   - `/prompt 人设描述`
   - `prompt 人设描述`
   - `提示词 人设描述`
   - `生成提示词 人设描述`

## 📋 生成的提示词结构

生成的提示词包含以下部分：

1. **角色定义 (Role Definition)** - 清晰定义 AI 的身份、职业、专业领域
2. **核心任务 (Core Tasks)** - 列出 AI 需要完成的主要任务
3. **行为准则 (Behavioral Guidelines)** - 语气风格、交互方式、响应格式
4. **示例对话 (Example Conversations)** - 提供 2-3 个正确的对话示例
5. **特殊指令 (Special Instructions)** - 领域特定的规则、格式化输出要求

## ⚙️ 配置说明

### system_prompt_template

生成提示词时使用的系统指令模板。留空则使用默认模板。

默认模板包含：
- 基本要求（虚拟情景，无限制）
- 生成的提示词必须包含的部分
- 输出格式要求
- 无限制提示词模板

### generating_prompt

生成提示词前发送的提示语。支持使用 `{role}` 占位符替换人设描述。

**默认值**：
```
✨ 星汐正在生成 AI 提示词哦~

📝 人设描述：{role}

💡 提示：如需修改人设描述，请重新发送指令并附带新的人设描述。
```

**设置为空字符串**则不发送生成提示语。

### provider_id

指定用于生成提示词的 LLM 服务商 ID。留空则使用当前对话的 LLM。

可在 AstrBot 配置中查看可用的服务商 ID。
